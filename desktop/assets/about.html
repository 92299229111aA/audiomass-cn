关于本应用

AudioMass 是一款完全在你的设备上运行的音频编辑器。所有音频处理都在本地完成， 不会上传任何文件，断网也能正常使用。

主要功能

  • 导入 MP3 / WAV / FLAC / OGG 等常见格式，波形可视化编辑
  • 淡入淡出、剪切、裁剪、复制、音量调整
  • 多轨模式：叠加音轨、拖动片段、交叉淡化、录制、混缩导出
  • 参数均衡器（EQ）、压缩、降噪、变速变调、BPM 检测
  • 麦克风录音，支持从系统音频设备采集
  • 导出 MP3 / WAV / FLAC，可编辑 ID3 标签
  • 工程本地保存与恢复

快捷键

大多数编辑快捷键使用 Shift + 按键 组合：

  • Shift + Z 撤销
  • Shift + C 复制选区
  • Shift + X 剪切选区
  • 空格 播放 / 暂停

录音权限

若麦克风录音不可用，请检查 Windows「设置 → 隐私和安全性 → 麦克风」中 是否已允许桌面应用访问麦克风。
